# 片道GO! 新着通知

[トヨタレンタカー「片道GO!」](https://cp.toyota.jp/rentacar/)のご利用可能車種一覧を10分おきに確認し、
指定したルート（出発エリア→返却エリア）の**新しく掲載された車**をスマホの [ntfy](https://ntfy.sh/) アプリに通知します。

通知には出発店舗・返却先・期間・車種・車両条件・予約電話番号が入り、タップすると電話をかけられます。

## しくみ

- cron-job.org から5分おきに GitHub Actions を起動して `notifier.py` を実行（GitHub 自身の定期実行は予備）
- 一覧の「出発」タブの全車両を読み取り、`state/seen.json`（既読リスト）と比べて変化を検出
- サイトでは受付終了の車も一覧に残り、「受付終了」の帯が付くだけ（HTMLでは `show-entry-end` クラス）なので、受付中かどうかを区別して扱う

| サイトの変化 | 通知 |
|---|---|
| 受付中の車が新しく出た | 🚗 新着（電話ボタンつき） |
| 受付終了だった車が受付中に戻った | 🔁 受付再開 |
| 通知済みの車が受付終了になった | ❌ 受付終了（元の通知を同じIDで書き換え） |
| 通知済みの車が一覧から消えた | ❌ 掲載終了（同上） |
| 最初から受付終了の車が出た | 通知しない |

- 新着が1回に9台以上あれば、8台を個別通知＋残りをまとめて通知
- 一覧が0件になった／ページ構造が変わった場合は、1回だけ警告を通知
- 「書き換え」は ntfy の sequence ID 機能を使用。対応していない端末では、別の通知として届きます

## 設定

**通知先**：Settings → Secrets and variables → Actions → Secrets に登録

| 名前 | 内容 |
|---|---|
| `NTFY_TOPIC` | ntfy のトピック名（推測されにくいランダムな文字列） |
| `NTFY_TOKEN` | 任意。ntfy.sh のアクセストークンを使う場合のみ |

**監視ルートと一覧**：Actions タブ →「ルート設定・一覧」→ Run workflow で、プルダウンから選んで実行

| 操作 | 内容 |
|---|---|
| 一覧を見る（登録中のルート） | 登録ルートごとに、今受付中の車を一覧で通知（🆕＝24時間以内の新着を先頭に、受付終了は除外） |
| 一覧を見る（選んだエリア） | プルダウンで選んだ出発→返却エリアの一覧を通知（登録はしない） |
| 追加 | ルートを1件追加し、そのルートの今の一覧も通知（初期設定の「全ルート」は最初の追加で置き換わります） |
| 削除 | 選んだルートを削除 |
| この1件だけにする | 他を消して選んだルートだけにし、その一覧も通知 |
| 確認だけ | 今のルート一覧をスマホに通知 |

ルートを変えるたびに、変更後のルート設定がスマホに届きます。設定は `config.json` に保存されます。

## スマホ側

1. App Store / Google Play で「ntfy」をインストール
2. ＋ボタン →「Subscribe to topic」→ `NTFY_TOPIC` と同じトピック名を入力
3. GitHub の Actions タブ →「片道GO! 新着チェック」→ Run workflow で「テスト通知だけ送る」にチェックして実行 → 通知が届けば完了

## 手元での確認

```sh
pip install -r requirements.txt pytest
pytest -q tests
python notifier.py --dry-run          # 通知せず結果を表示
```
